# BuyFinix

Responsive multi-page storefront and account/admin prototype. No build command or package install is needed.

Open `index.html` locally, or upload the folder contents to any static hosting provider.

## Production integration still required

- WhatsApp or email OTP provider
- Secure database and server-side role authorization
- SSLCommerz or manual payment verification
- Encrypted credential inventory and delivery worker

The prototype intentionally does not store customer passwords or service credentials in browser storage.
